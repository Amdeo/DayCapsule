# Timeline 卡片整壳入场与加载点配色设计文档

**日期**: 2026-03-17
**功能**: 让整张卡片壳体使用 `FadeInRight` 入场，并让加载中的 3 个点分别对应三种卡片主题色

---

## 背景

当前时间轴已经具备卡片加载时的错峰 `FadeInRight`，但动画仅作用在卡片内部内容层，卡片外层阴影、圆角背景和内容不是一体进入。

新的目标有两个：

- 整张卡片壳体一起 `FadeInRight`
- 切换视图时的 3 个加载点，分别使用文字、照片、语音三种主题色

同时保持以下约束：

- 时间点圆点和时间文本不参与入场动画
- 卡片移除时仍然没有退出动画
- 不重新引入粗框残影问题

---

## 设计目标

### 核心目标

- 卡片外壳、阴影、圆角背景和内部内容作为一个整体入场
- 时间轴骨架元素保持静止
- `DotsLoader` 的 3 个点具备明确的主题色映射

### 非目标

- 不给时间点圆点和时间文本添加入场动画
- 不引入新的退出动画
- 不修改加载点的跳动节奏和整体布局

---

## 方案对比

### 方案 1：把整行 `EntryMarker` 一起做 `FadeInRight`

**结论**: 不采用

原因：
- 会连时间点圆点和时间文本一起动
- 与已确认的需求不符
- 更容易把之前的粗框残影问题带回来

### 方案 2：把 `FadeInRight` 上移到 `EntryCard` 最外层容器

**结论**: 采用

做法：
- 保持 `Timeline.v2.tsx` 外层行容器静态
- 将 `FadeInRight` 从 `EntryCard` 的内部内容层移动到卡片最外层容器
- 内部内容层恢复为静态或仅保留必要的内部 layout 行为

优点：
- 整张卡片一体进入，视觉更完整
- 时间轴骨架不动，层级清晰
- 风险仍控制在 `EntryCard` 内部，而不是扩散到整行

### 方案 3：双层动画，壳体和内容分别进入

**结论**: 不采用

原因：
- 过度设计
- 两层叠加更容易显得花
- 增加残影和时序错位风险

## 最终设计

### 1. 卡片动画层级

`FadeInRight` 从 [src/components/EntryCard.tsx](/Users/cooper/Documents/code/MemoryCapsule/app/src/components/EntryCard.tsx) 当前的内部内容层，上移到最外层卡片容器，也就是承载：

- 阴影
- 圆角
- 背景色
- 卡片整体位移样式

的那层 `Animated.View`。

这样效果是：

- 整张卡片作为一个整体从右向左淡入
- 卡片内部内容不再单独晚一步出现
- 时间点圆点和时间文本保持静止

### 2. 退出行为

卡片移除时继续保持：

- 无 `FadeOut`
- 无 `exiting`
- 无其他退场过渡

即：旧卡片直接消失，新卡片负责入场。

### 3. 加载点配色

[src/components/Timeline.v2.tsx](/Users/cooper/Documents/code/MemoryCapsule/app/src/components/Timeline.v2.tsx) 中的 `DotsLoader` 采用固定三色映射：

- 第 1 个点：文字主题色 `#A491D3`
- 第 2 个点：照片主题色 `#77C9D4`
- 第 3 个点：语音主题色 `#F5A623`

仅修改颜色，不修改：

- 跳动顺序
- 延迟节奏
- 点的尺寸
- 点之间间距

## 技术实现方向

### `EntryCard.tsx`

调整点：

- 把 `entering={FadeInRight...}` 从当前内部 `Animated.View` 挪到最外层 `entry-card-container`
- 内部内容层去掉这层 entering，避免双重进入
- 保持 `enterDelay` prop 的传递方式不变

关注点：

- `cardAnimatedStyle` 与 `FadeInRight` 要能共存
- 不能破坏滑动、按压、ActionSheet、展开等现有交互

### `Timeline.v2.tsx`

调整点：

- 保持 `enterDelay` 的错峰计算和透传
- `DotsLoader` 改为三种固定主题色

不改：

- `EntryMarker` 结构
- 时间点样式
- 加载点的弹跳逻辑

---

## 风险与控制

### 风险 1：整张卡片外壳一起动后，粗框残影回归

控制方式：

- 只把动画上移到 `EntryCard` 最外层，不扩展到 `EntryMarker`
- 不增加任何退出动画
- 若残影回归，优先回退到“只动内容层”，而不是继续扩大动画范围

### 风险 2：外层位移动画与卡片左滑位移冲突

控制方式：

- 保持现有 `cardAnimatedStyle` 逻辑
- 手工验证左滑打开 ActionSheet 时是否存在叠加异常

### 风险 3：加载点颜色过于杂乱

控制方式：

- 只用三种已存在主题色
- 不增加额外发光、渐变或透明度变化
