# Data Model – LifeLog 多模态记录

## Entity: LifeLogEntry
- **Primary Key**: `id` (UUID v4)
- **Fields**:
  - `created_at` (ISO timestamp, indexed)
  - `updated_at` (ISO timestamp)
  - `title` (string, optional)
  - `text_content` (rich text JSON, nullable)
  - `mood` (emoji code, nullable, validated列表)
  - `weather` (enum: sunny|cloudy|rainy|snow|other, nullable)
  - `location_lat` (decimal 8,6, nullable)
  - `location_lng` (decimal 9,6, nullable)
  - `location_name` (string, nullable)
  - `tags_manual` (string[])
  - `tags_ai` (string[], generated by AI provider)
  - `media_count` (integer, default 0, constraint ≤ 9)
  - `audio_duration_sec` (integer, nullable, constraint 30–300)
  - `sync_status` (enum: draft|pending|synced|failed)
  - `sync_retry_count` (integer, default 0, max 5)
  - `reminder_enabled` (boolean, default false)
- **Indexes**:
  - `idx_created_at`
  - `idx_tags_manual`（FTS5 虚拟表 `entry_tags_fts` 用于全文搜索）
  - `idx_location`
- **Relationships**:
  - 1:N with `MediaAttachment` (`entry_id`)
  - 1:N with `ReminderLog`
- **State Transitions**:
  - `draft` → `pending`（保存成功且可同步）
  - `pending` → `synced`（云同步成功）
  - `pending` → `failed`（同步失败，retry_count++）
  - `failed` → `pending`（用户或系统重试）

## Entity: MediaAttachment
- **Primary Key**: `id` (UUID)
- **Fields**:
  - `entry_id` (FK → LifeLogEntry.id)
  - `type` (enum: photo|audio)
  - `uri_local` (string, absolute path, encrypted at rest)
  - `thumbnail_uri` (string, for photo, cached 200x200)
  - `filesize_bytes` (integer)
  - `duration_sec` (integer, for audio)
  - `created_at` (timestamp)
  - `checksum` (string sha256,用于重复检测)
- **Indexes**:
  - `idx_media_entry`
  - `idx_media_checksum`
- **Constraints**:
  - `type=photo` 时必须存在 `thumbnail_uri`
  - `type=audio` 时必须存在 `duration_sec`

## Entity: Tag
- **Primary Key**: `id` (UUID)
- **Fields**:
  - `name` (string, unique per user, case-insensitive)
  - `origin` (enum: manual|ai)
  - `created_at` (timestamp)
  - `usage_count` (integer,维护增减)
- **Relationships**:
  - N:M with `LifeLogEntry` via `entry_tags` join table
- **Indexes**:
  - `idx_tag_name` (UNIQUE)

## Join Table: entry_tags
- **Fields**:
  - `entry_id` (FK)
  - `tag_id` (FK)
  - `source` (enum: manual|ai)
- **Composite PK**: (`entry_id`, `tag_id`, `source`)

## Entity: ReminderLog
- **Primary Key**: `id` (UUID)
- **Fields**:
  - `entry_id` (FK)
  - `reminder_type` (enum: on_this_day|custom)
  - `scheduled_for` (date)
  - `delivered_at` (timestamp nullable)
  - `status` (enum: scheduled|sent|skipped)
- **Indexes**:
  - `idx_reminder_schedule`

## Entity: SyncQueueItem
- **Primary Key**: `id` (UUID)
- **Fields**:
  - `entry_id` (FK)
  - `operation` (enum: create|update|delete)
  - `payload_path` (string, encrypted temp file)
  - `created_at` (timestamp)
  - `attempts` (int, default 0)
  - `last_error` (string nullable,脱敏信息)
- **Constraints**:
  - `attempts ≤ 5`，超过进入 `failed` 状态并提示用户

## Relationships Diagram (文本描述)
- LifeLogEntry ← MediaAttachment（1:many）
- LifeLogEntry ↔ Tag（many:many via entry_tags）
- LifeLogEntry ← ReminderLog（1:many）
- LifeLogEntry ← SyncQueueItem（1:many，pending 同步项）

## Validation Rules
- 每条记录检查照片数量 ≤ 9，语音长度 30–300 秒。
- 保存时若无定位权限，允许 `location_*` 为空，并在 UI 提示。
- 同步状态转换时必须记录审计日志（脱敏）。
- FTS5 表在标签、文本内容更新后同步刷新。

## Storage & Indexing Notes
- SQLite 使用 WAL 模式、自动压缩；备份前需关闭 WAL。
- AsyncStorage 仅存轻量配置（主题、字体、设置 flags）。
- 媒体文件统一落在 app 私有目录 `/media/{entryId}/`，并生成缩略图缓存 `/thumbs/`。
