# 设计文档: 沉浸式单页流 UI/UX (Immersive One-Page Flow UI/UX)

## 概述

本设计文档提出了 MemoryCapsule 应用全新的交互范式——“沉浸式单页流（Immersive One-Page Flow）”，旨在大幅提升用户在记录和回顾生活瞬间时的流畅性和效率。传统应用中常见的页面跳转（Navigation）模式，在用户进行快速记录或沉浸式浏览时会造成思维中断。本设计通过**“叠加（Overlay）”**和**“形变（Morph）”**而非页面跳转的方式，将大部分核心操作整合在单一时间线视图中，提供无缝、直观且单手友好的用户体验。

## 交互原则

本设计的核心交互原则是：**“不要跳转（Don't Navigate），而是叠加（Overlay）与形变（Morph）。”**

*   **叠加 (Overlay):** 当需要进行辅助操作（如拍照取景器、记录详情）时，并非切换到新页面，而是以浮层、半屏或全屏遮罩的形式，在当前内容上方呈现，保持原有页面的视觉上下文。
*   **形变 (Morph):** 当界面元素发生状态变化（如输入框唤起键盘、卡片展开详情）时，通过流畅的动画进行视觉形变，而非生硬的切换，增强用户对界面变化的感知和心理连贯性。

## 关键 UI 元素

### 核心“胶囊”底栏 (The Capsule Dock)

一个悬浮在屏幕底部，融合了高频操作入口的圆角矩形胶囊状底栏。它始终可见，但能根据用户交互进行形变或吸附。

*   **视觉特征:**
    *   屏幕底部悬浮，圆角矩形设计。
    *   背景采用半透明毛玻璃效果，提供轻微的视觉模糊，同时不完全遮挡内容。
*   **常驻功能元素:**
    *   **左侧：`#` 图标 (快速筛选/搜索入口):** 点击或长按触发搜索/筛选浮层。
    *   **中间：`输入框` (快捷文字记录入口):** 显示“输入想法...”占位符，点击直接唤起键盘。
    *   **右侧：`相机图标` (多模态记录):**
        *   **单击:** 唤起半屏拍照/选图取景器。
        *   **长按:** 启动语音录音。

## 交互流程

### 1. 极速输入 (Fast Input)

摒弃传统“发布页”模式，将输入操作直接嵌入主时间线页面。

*   **1.1 文字记录**
    *   **用户动作:** 点击底部的“输入想法...”输入框。
    *   **系统反馈:** 键盘从底部弹起，同时“胶囊底栏”流畅形变并自动吸附在键盘上方。输入框变为可编辑状态，右侧的相机图标变为“发送/保存”箭头。
    *   **结果:** 用户输入文字，点击“发送/保存”后，键盘收起，新创建的记录卡片以动画形式直接插入到时间线顶部（或用户指定位置）。整个过程无页面跳转。

*   **1.2 语音记录**
    *   **用户动作:** 长按右侧的 `[ 📷 ]` 图标（在长按时，图标会动态变为麦克风图标）。
    *   **系统反馈:** 屏幕上出现录音波纹动画或录音时长指示。手指松开即停止录音并保存。若手指向上滑动到特定区域则取消录音。
    *   **结果:** 语音记录卡片（带有播放按钮和录音时长）瞬间插入时间线。后台开始进行语音转文字，转写结果会自动更新到卡片中。

*   **1.3 拍照/选图记录**
    *   **用户动作:** 单击右侧的 `[ 📷 ]` 图标。
    *   **系统反馈:** 不进行全屏页面跳转。而是从底部弹出一个**占屏幕 60-70% 高度的“取景器半屏卡片 (Bottom Sheet)”**。该卡片包含相机预览、拍照按钮、闪光灯控制、前后摄像头切换，以及下方切换到相册选择模式的入口。
    *   **结果:** 用户在半屏卡片内完成拍照或选图（支持多选）。拍照后照片缩略图会显示在卡片内。用户可选择关闭卡片（向下滑动），或者点击“完成/添加”按钮。照片会随卡片关闭动画一同“飞入”时间线，生成新的记录卡片。

### 2. 查看详情 (View Details)

避免跳转到独立的详情页，保持用户在时间线上的沉浸感。

*   **用户动作:** 点击时间线上的任意记录卡片。
*   **系统反馈:** 被点击的卡片会以**“原位放大 (Hero Animation)”**的效果，或者作为一个**“全屏遮罩层 (Modal)”**优雅地覆盖在当前页面上方，时间线背景则施加高斯模糊效果。详情页内包含更完整的记录内容（大图、富文本、完整语音转写、标签、地点、天气等）和编辑、删除等操作。
*   **结果:** 用户在浮层中查看和编辑详情。向下滑动浮层（Pull-down to dismiss）即可流畅地关闭详情，无缝回到时间线刚才的浏览位置，无需“返回”操作。

### 3. 搜索与筛选 (Search & Filter)

将搜索功能也整合在主页面，避免分散用户注意力。

*   **用户动作:**
    *   **方式一 (下拉刷新式):** 在时间线顶部向下拉动（类似刷新操作，但触发阈值更高）。
    *   **方式二 (快捷入口):** 点击左侧胶囊底栏中的 `[ # ]` 图标。
*   **系统反馈:** 页面顶部会平滑地滑出搜索栏和常用标签云（Tag Cloud）。搜索栏下可能出现最近搜索历史和搜索建议。
*   **结果:** 用户输入关键词或选择标签后，时间线上的记录会实时进行过滤。不符合条件的记录会逐渐淡出或被收起，符合条件的记录则重新排列或突出显示。再次下拉或点击 `[ # ]` 可收起搜索/筛选界面，恢复完整时间线。

## 架构考量 (UI/UX 层面)

### 模块化设计原则 (UI/UX 层面)
*   **单页原则:** 绝大多数用户交互发生在单个主视图上，通过浮层和动画模拟“页面”切换。
*   **组件化:** 将胶囊底栏、取景器半屏卡片、详情浮层、搜索/筛选浮层等设计为高度独立的 React Native 组件。
*   **动画驱动:** 大量依赖声明式动画库实现平滑的界面形变和过渡，以支持“叠加”和“形变”的原则。

## 技术选型建议 (React Native Libraries)

为实现上述流畅且复杂的交互效果，以下 React Native 库是推荐的关键技术：

*   **`@gorhom/bottom-sheet`**: 用于实现半屏和全屏的可拖拽浮层（如拍照取景器和记录详情页），支持手势关闭。
*   **`react-native-reanimated`**: 提供强大的声明式动画 API，实现胶囊底栏随键盘吸附、卡片放大展开、元素“飞入”等复杂共享元素过渡 (Shared Element Transition) 动画，确保交互的流畅性和高性能。
*   **`react-native-keyboard-controller`**: 精确控制键盘的出现和消失事件，使胶囊底栏能够无缝地吸附在键盘上方，提供类似原生聊天应用的输入体验。
*   **`react-native-gesture-handler`**: 增强手势识别能力，支持更复杂的下拉刷新、长按等交互。
