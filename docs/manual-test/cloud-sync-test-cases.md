## 测试说明

- 设备 A、设备 B 登录同一账号
- 云同步入口、设置页、同步状态页均可访问
- 每条用例都建议记录截图、录像、实际现象和最终结论
- 建议优先执行 `P0` 用例，再补 `P1` 用例

---

## 字段说明

| 字段 | 说明 |
| --- | --- |
| 编号 | 用例唯一编号 |
| 优先级 | `P0` 高优先级，`P1` 次高优先级 |
| 场景 | 测试的大类 |
| 目标 | 本用例验证点 |
| 前置条件 | 执行前必须满足的条件 |
| 操作步骤 | 用户实际执行步骤 |
| 预期结果 | 通过标准 |
| 实际结果 | 测试时填写 |
| 结论 | 通过 / 失败 / 部分通过 |

### TC-CS-001

| 字段 | 内容 |
| --- | --- |
| 编号 | TC-CS-001 |
| 优先级 | P0 |
| 场景 | 首次同步 / 云恢复 |
| 目标 | 本地为空、云端有数据时，验证选择“从云恢复”可成功恢复本地 |
| 前置条件 | 1. 设备 A 本地无记录。2. 云端已有文本、照片、语音数据。3. 设备 B 已确认这些数据存在。 |
| 操作步骤 | 1. 设备 A 登录测试账号。2. 确认首页为空。3. 进入设置页开启云同步。4. 首次同步选择“从云端恢复”。5. 等待流程完成。6. 返回首页查看文本、照片、语音记录。7. 打开详情检查照片和语音可用性。8. 打开同步状态页查看时间与错误状态。 |
| 预期结果 | 1. 云端数据完整恢复到 A。2. 无重复记录。3. 照片可显示。4. 语音可播放。5. 状态页无长期异常。 |
