## 历史说明

这份 plan 是最初“大一统云端模式前端集成”方案的执行清单。它曾尝试在同一份计划里同时推进：

- 认证与 token 刷新
- `RemoteDataSource`
- 云端模式切换
- 语音补丁
- 媒体 cache

后续实践证明，这种组织方式会让边界越来越模糊，尤其是在：

- 语音后台上传已经拆成独立任务后
- 前端本地优先同步内核已经单独落地后
- 后端增量同步协议已经独立演进后

继续把这些变化追加回本文件，只会制造“历史文档”和“当前子任务文档”并存且互相冲突的问题。
