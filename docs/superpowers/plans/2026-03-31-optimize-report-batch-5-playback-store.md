> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Introduce one new playback-only Zustand store file, remove playback state from `entryStore`, and update `EntryCard` plus the small set of playback-related tests that currently mock `entryStore` for `currentPlayingId`. No search/filter state moves in this batch.

**Tech Stack:** TypeScript, React Native, Zustand, Jest, Testing Library

- [ ] **Step 3: Write the minimal implementation**

Create `app/src/store/entryPlaybackUIStore.ts`:

```ts
import { create } from 'zustand';

interface EntryPlaybackUIStore {
  currentPlayingId: string | null;
  setCurrentPlayingId: (id: string | null) => void;
}

export const useEntryPlaybackUIStore = create<EntryPlaybackUIStore>((set) => ({
  currentPlayingId: null,
  setCurrentPlayingId: (id) => set({ currentPlayingId: id }),
}));
```

In `app/src/store/entryStore.ts`, remove from the interface and initial state:

```ts
currentPlayingId: string | null;
setCurrentPlayingId: (id: string | null) => void;
```

and remove:

```ts
currentPlayingId: null,
setCurrentPlayingId: (id) => set({ currentPlayingId: id }),
```

In `app/src/components/EntryCard.tsx`, replace:

```ts
const currentPlayingId = useEntryStore((state) => state.currentPlayingId);
const setCurrentPlayingId = useEntryStore((state) => state.setCurrentPlayingId);
```

with:

```ts
import { useEntryPlaybackUIStore } from '@/src/store/entryPlaybackUIStore';

const currentPlayingId = useEntryPlaybackUIStore((state) => state.currentPlayingId);
const setCurrentPlayingId = useEntryPlaybackUIStore((state) => state.setCurrentPlayingId);
```

Do not move any other state in this batch.
