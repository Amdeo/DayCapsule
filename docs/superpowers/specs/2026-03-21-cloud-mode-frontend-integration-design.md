## 历史背景

这份文档记录的是最初“云端模式前端集成”的大方案。它当时试图一次性覆盖：

- `RemoteDataSource` 直连远端 API 的云端模式
- 登录 / 注册与 token 刷新
- 本地 / 云端模式切换
- 语音录制链路调整
- 媒体 cache 化

随着实现推进，这个方案被证明范围过大，且不同子问题之间的边界不够清晰，后续已经拆成更小、可独立验证的任务。
