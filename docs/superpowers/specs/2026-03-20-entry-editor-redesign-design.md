# 编辑页重做设计规格

**日期**：2026-03-20  
**状态**：已实现

## 实现记录

- **实现日期**：2026-03-20
- **实现结果**：
  - `EntryEditor` 已重做为固定顶部栏 + 大正文输入区 + 固定底部标签工具条。
  - 文本查看页进入编辑页的链路保持不变，仍为 `文本卡 -> 全屏查看页 -> 编辑`。
  - 保存行为与标签数据格式保持兼容，没有新增草稿或离开确认流程。
- **实现偏差**：
  - 当前仍保留在 `EntryEditor.tsx` 单文件内完成重组，没有继续拆成 `EntryEditorBody` / `EntryEditorTagDock` 独立文件，后续如果文件继续变大再拆。

## 背景

当前 [`EntryEditor.tsx`](/Users/cooper/Documents/code/MemoryCapsule/app/src/components/EntryEditor.tsx) 的问题不是单纯输入框高度太小，而是整个页面仍然是“表单堆叠”结构：

- 正文输入区只是若干 section 里的一个块，视觉权重不够。
- 标签、建议、时间信息和正文并列，抢占主编辑空间。
- 用户从文本查看页进入编辑后，没有明显进入“写作状态”的感觉。

这次目标不是继续微调 `minHeight`，而是把文本编辑页整体重做成更偏写作的页面。

## 设计目标

- 打开编辑页后，优先进入“写作状态”。
- 正文输入区成为主舞台，默认接近整屏高度。
- 标签编辑从主表单里退出，降级为底部固定工具条。
- 保存动作仍然清晰直接，不增加额外交互层级。
- 新编辑页与现有链路保持一致：
  `文本卡 -> 全屏查看页 -> 编辑`

## 方案结论

本次确定采用混合方案：

- 正文区采用 `A 沉浸编辑页`
- 标签区采用 `C 底部工具式`
- 保存动作保留在顶部右上角
- 标签区固定在底部，不跟随正文一起滚动

## 页面结构

### 1. 顶部栏

顶部保留三段式结构：

- 左侧：返回
- 中间：标题“编辑记录”
- 右侧：保存

要求：

- 保存为主操作，视觉上明确可点。
- 顶部始终固定，不随正文滚动。
- 页面整体应更接近正式内容页，而不是底部弹出的轻量表单。

### 2. 正文主编辑区

正文区是整页主舞台。

要求：

- 默认就是大输入面，接近整屏。
- 用户进入编辑页后，第一视觉落点就是正文。
- 正文区不再只是普通灰底输入框，而是一个更完整的写作表面。
- 文本输入可随内容增长继续向下扩展，不做小高度限制。
- 视觉目标是“进入写作状态”，而不是“填写一个字段”。

### 3. 底部标签工具条

标签区从主表单中拆出，作为底部固定工具条。

要求：

- 固定在底部，不随正文滚动。
- 作为辅助编辑区存在，不抢正文主层级。
- 继续支持：
  - 常用标签点选
  - 已选标签预览
  - 手动输入标签
  - 建议标签

但视觉上需要更像辅助工具，而不是第二个主编辑面。

### 4. 补充信息区

创建时间等元信息不再和正文抢主区域。

要求：

- 可以保留，但应弱化。
- 更适合放在正文区下方或底部工具区上方的次级位置。
- 不应成为首屏主视觉的一部分。

## 交互规则

### 进入编辑

- 用户从文本查看页右上角 `编辑` 进入编辑页。
- 进入后直接获得大正文输入区，不需要再额外点一次小输入框来“找编辑状态”。

### 编辑正文

- 用户主要在正文区完成编辑。
- 正文区支持长文本输入，内容增多时自然增长。
- 不以小 textarea 的方式限制输入。

### 编辑标签

- 标签相关操作在底部固定工具条中完成。
- 标签输入是次级操作，不应打断正文编辑节奏。

### 保存与退出

- 右上角 `保存` 直接提交编辑结果。
- 左上角返回用于放弃或退出当前编辑态。
- 后续实现时可以保留现有“返回即关闭”的行为，不在本次设计中新增复杂的未保存提示流程。

## 组件边界

建议把现有 [`EntryEditor.tsx`](/Users/cooper/Documents/code/MemoryCapsule/app/src/components/EntryEditor.tsx) 拆成更清晰的结构：

- `EntryEditorPage`
  - 页面壳层
  - 顶部栏
  - 页面级布局
- `EntryEditorBody`
  - 正文主编辑区
- `EntryEditorTagDock`
  - 底部固定标签工具条

如果当前实现不需要立刻拆成多个文件，至少也应在组件内部形成这三个清晰区域，避免继续把所有逻辑堆在一个表单 ScrollView 中。

## 不在本次范围内

- 照片编辑页、语音编辑页重做
- 查看页内直接切换编辑态
- 富文本能力
- 草稿自动保存
- 新增复杂的离开确认流程

## 验收标准

- 编辑页首屏明显以正文编辑为主，不再是多 section 表单堆叠。
- 正文输入区默认接近整屏，显著大于当前版本。
- 标签区固定在底部，视觉和功能都作为辅助编辑区存在。
- 保存动作仍位于顶部右上角。
- 编辑页与现有文本查看页链路顺畅衔接。
- 长文本编辑体验明显优于当前实现。
