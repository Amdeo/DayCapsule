# 手动测试计划

**版本**：存储重构三阶段（MMKV + 游标分页 + Tags 规范化）
**测试环境**：iOS 模拟器 / 真机（需 EAS Build 或 custom dev client）
**约定**：✅ 通过 ❌ 失败 ⚠️ 部分通过

---

## 前置条件

- [ ] 应用已通过 EAS Build 安装（MMKV 需要原生模块）
- [ ] 首次安装或已清除应用数据
- [ ] 开启 Metro 日志，便于观察启动序列输出

---

## T1 应用启动与初始化

### T1-1 首次启动

**步骤**：
1. 冷启动应用

**预期日志（Metro 控制台）**：
```
✅ 文件系统初始化成功
✅ 音频系统初始化成功
✅ SQLite 数据库初始化成功
📭 没有需要迁移的数据
✅ Tags 规范化迁移完成
```

**验证点**：
- [ ] 无崩溃，正常进入主界面
- [ ] 不出现"初始化失败"弹窗
- [ ] Timeline 显示空状态（无记录）

---

### T1-2 重复启动（幂等性）

**步骤**：
1. 退出应用，再次冷启动

**预期日志**：
```
✅ 数据已经迁移过，跳过迁移
✅ Tags 规范化迁移完成（立即返回，无 DB 操作）
```

**验证点**：
- [ ] 启动速度与首次相当
- [ ] 数据未重复或丢失

---

## T2 基础 CRUD

### T2-1 新增文字记录

**步骤**：
1. 点击新建按钮
2. 输入内容："今天天气很好"
3. 添加标签："日常"、"心情"
4. 保存

**验证点**：
- [ ] 记录立即出现在 Timeline 顶部
- [ ] 内容、标签显示正确
- [ ] 时间戳显示为"刚刚"

---

### T2-2 新增照片记录

**步骤**：
1. 新建记录，选择照片类型
2. 从相册选择一张图片
3. 保存

**验证点**：
- [ ] 缩略图正常显示
- [ ] 记录出现在 Timeline

---

### T2-3 新增语音记录

**步骤**：
1. 新建记录，选择语音类型
2. 录制 5 秒语音
3. 停止并保存

**验证点**：
- [ ] 录音时长显示正确
- [ ] 可以播放录音
- [ ] 记录出现在 Timeline

---

### T2-4 编辑记录

**步骤**：
1. 长按或点击已有文字记录
2. 修改内容为："今天天气很好，出去散步了"
3. 修改标签：删除"心情"，添加"运动"
4. 保存

**验证点**：
- [ ] 内容更新正确
- [ ] 标签更新正确（"日常"、"运动"）
- [ ] Timeline 中显示更新后内容

---

### T2-5 删除记录

**步骤**：
1. 对任意记录执行删除操作

**验证点**：
- [ ] 记录从 Timeline 消失
- [ ] 重启应用后记录仍不存在

---

## T3 数据持久化

### T3-1 重启后数据保留

**步骤**：
1. 新增 3 条不同类型的记录（文字、照片、语音）
2. 完全退出应用（非后台）
3. 重新启动

**验证点**：
- [ ] 3 条记录全部保留
- [ ] 内容、标签、媒体文件均正确
- [ ] 顺序与退出前一致（时间倒序）

---

### T3-2 设置持久化（MMKV）

**步骤**：
1. 进入设置页
2. 开启"自动备份"
3. 完全退出应用
4. 重新启动，进入设置页

**验证点**：
- [ ] "自动备份"开关仍为开启状态
- [ ] 其他设置项也保持不变

---

---

## T4 游标分页（无限滚动）

### T4-1 首页加载

**前置**：数据库中至少有 25 条记录（可批量新增测试数据）

**步骤**：
1. 打开 Timeline

**验证点**：
- [ ] 首次只加载 20 条记录
- [ ] 列表底部无 loading 指示器（未触发翻页）

---

### T4-2 滚动触发翻页

**步骤**：
1. 在 Timeline 中向上滚动到底部

**验证点**：
- [ ] 底部出现 loading 指示器（ActivityIndicator）
- [ ] 加载完成后，新记录追加到列表末尾
- [ ] loading 指示器消失
- [ ] 总记录数 = 首页 20 + 新加载数量

---

### T4-3 全部加载完毕

**步骤**：
1. 持续滚动直到所有记录加载完

**验证点**：
- [ ] 最后一页加载后，底部不再出现 loading 指示器
- [ ] 继续滚动不触发新请求

---

### T4-4 过滤后分页重置

**步骤**：
1. 已滚动到第 2 页（40 条）
2. 切换过滤类型为"照片"

**验证点**：
- [ ] 列表重置，只显示照片类型的前 20 条
- [ ] 游标重置（从头开始分页）
- [ ] 再次滚动可继续翻页

---

### T5-2 单标签过滤

**步骤**：
1. 在过滤栏选择标签"工作"

**验证点**：
- [ ] 只显示含"工作"标签的记录

---

### T5-3 多标签 AND 过滤

**步骤**：
1. 同时选择标签"工作"和"重要"

**验证点**：
- [ ] 只显示同时含"工作"和"重要"的记录

### T5-4 取消标签过滤

## T8 自动备份

### T8-1 进入后台触发备份

**前置**：设置中开启"自动备份"

**步骤**：
1. 在应用内新增 1 条记录
2. 按 Home 键将应用切换到后台
3. 等待 2-3 秒
4. 重新打开应用

**验证点**：
- [ ] Metro 日志中无"自动备份失败"错误
- [ ] 备份文件存在（可在设置/备份页查看）

---

### T8-2 关闭自动备份

**步骤**：
1. 设置中关闭"自动备份"
2. 切换应用到后台

**验证点**：
- [ ] Metro 日志中无备份相关日志
- [ ] 不触发备份操作

---
