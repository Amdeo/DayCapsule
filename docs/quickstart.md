## 安装

### 系统要求

- **iOS**: 15.0 或更高版本
- **Android**: 12 或更高版本
- **Node.js**: 18.x 或更高版本
- **npm**: 9.x 或更高版本

### 步骤 1: 克隆仓库

```bash
git clone https://github.com/yourusername/MemoryCapsule.git
cd MemoryCapsule
```

### 步骤 2: 安装依赖

```bash
npm install
```

### 步骤 3: 安装平台特定依赖

**iOS（仅 macOS）**
```bash
cd ios && pod install && cd ..
```

**Android**
```bash
# 确保已安装 Android SDK
# 设置 ANDROID_HOME 环境变量
export ANDROID_HOME=$HOME/Library/Android/sdk
```

### 步骤 4: 启动开发服务器

```bash
npm start
```

### 步骤 5: 运行应用

**iOS**
```bash
npm run ios
```

**Android**
```bash
npm run android
```

## 基本功能

### 1. 快速记录 📸

#### 拍照记录
1. 点击主屏幕的 **+** 按钮
2. 选择 **拍照**
3. 拍摄照片
4. 添加标签、心情、位置等信息
5. 点击 **保存**

**提示**: 使用快速拍照模式可在 ≤3 次点击内完成记录

#### 文字记录
1. 点击主屏幕的 **+** 按钮
2. 选择 **文字**
3. 输入内容
4. 点击 **保存**

#### 语音记录
1. 点击主屏幕的 **+** 按钮
2. 选择 **语音**
3. 点击 **开始录制**
4. 说话（应用会自动转写）
5. 点击 **停止**
6. 点击 **保存**

### 2. 浏览时间线 📅

#### 切换视图
- **日视图** - 按小时查看今天的记录
- **周视图** - 查看本周的活动热度
- **月视图** - 查看本月的日历热力图
- **年视图** - 查看全年的统计概览

#### 导航
- 向左/右滑动切换日期
- 点击日期快速跳转
- 点击记录卡片查看详情

### 3. 搜索和筛选 🔍

#### 全文搜索
1. 点击搜索图标
2. 输入关键词
3. 查看搜索结果

#### 应用筛选
1. 点击 **筛选** 按钮
2. 选择筛选条件：
   - **标签** - 按标签筛选
   - **心情** - 按心情筛选
   - **日期** - 按日期范围筛选
   - **地点** - 按地点筛选
3. 点击 **应用**

#### 导出结果
1. 在搜索结果页面点击 **导出**
2. 选择格式：PDF、Word、CSV 或 JSON
3. 选择保存位置

### 4. AI 标签建议 🤖

#### 自动标签
1. 拍照后，应用会自动识别照片内容
2. 在 **AI 标签建议** 部分查看建议
3. 点击标签进行选择/取消选择
4. 点击 **应用** 将选中的标签添加到记录

#### 管理标签
- 点击标签可查看相关记录
- 长按标签可编辑或删除
- 使用标签进行快速筛选

### 5. 设置和隐私 ⚙️

#### 主题设置
1. 打开 **设置**
2. 选择 **显示**
3. 选择主题：浅色、深色或自动

#### 字体大小
1. 打开 **设置**
2. 选择 **显示**
3. 调整字体大小：小、中或大

#### 应用锁定
1. 打开 **设置**
2. 选择 **安全**
3. 启用 **应用锁定**
4. 选择认证方式：生物识别或密码

#### 隐私设置
1. 打开 **设置**
2. 选择 **隐私**
3. 管理数据收集、位置追踪等设置

## 常见问题

### Q: 如何备份我的数据？
A: 应用支持自动云备份（需配置）。您也可以手动导出数据为 JSON 格式。

### Q: 如何恢复已删除的记录？
A: 已删除的记录无法恢复。建议定期备份重要数据。

### Q: 应用支持离线使用吗？
A: 是的，应用采用离线优先架构。所有数据存储在本地，网络恢复后自动同步。

### Q: 如何更改应用语言？
A: 应用目前支持中文和英文。语言设置跟随系统设置。

### Q: 数据是否安全？
A: 是的，所有数据使用 AES-256-GCM 加密存储在本地。数据不会上传到云端。

## 故障排除

### 应用无法启动

**症状**: 应用启动后立即崩溃

**解决方案**:
1. 清除应用缓存：`npm run clean`
2. 重新安装依赖：`npm install`
3. 重新构建应用：`npm run ios` 或 `npm run android`

### 权限被拒绝

**症状**: 无法访问相机、相册等

**解决方案**:
1. 打开系统设置
2. 找到 MemoryCapsule 应用
3. 授予所需权限
4. 重启应用

### 搜索无结果

**症状**: 搜索返回空结果

**解决方案**:
1. 检查是否有记录存在
2. 尝试使用不同的关键词
3. 清除筛选条件
4. 检查数据库是否已初始化

### 性能问题

**症状**: 应用运行缓慢或卡顿

**解决方案**:
1. 清除应用缓存
2. 关闭其他应用
3. 重启设备
4. 检查可用存储空间

### 语音转写不工作

**症状**: 录音后没有转写结果

**解决方案**:
1. 检查网络连接
2. 检查麦克风权限
3. 检查腾讯云 ASR 配置
4. 查看应用日志获取详细错误信息
